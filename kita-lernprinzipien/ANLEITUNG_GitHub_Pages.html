1

GitHub-Account erstellen & Repository anlegen

1

Gehe auf github.com und erstelle einen kostenlosen Account

Öffne github.com in deinem Browser und klicke oben rechts auf „Sign up". Wähle eine E-Mail-Adresse und ein Passwort. Der kostenlose Plan (Free) reicht vollkommen aus.

💡Tipp für den Benutzernamen: Wähle etwas Professionelles wie tanja-todte oder bfs-kita-eichstaett – der Name erscheint später in der URL deiner Website.
2

Neues Repository erstellen

Nach dem Login: Klicke oben rechts auf das + Symbol → „New repository".

Fülle das Formular so aus:

📝
Repository name: kita-lernprinzipien (genau so, ohne Leerzeichen)
🔓
Visibility: Public auswählen – nur so funktioniert GitHub Pages kostenlos
☑️
„Add a README file" ankreuzen

Klicke dann auf den grünen Button „Create repository".

✅Du siehst jetzt dein neues leeres Repository – hier landen gleich deine Dateien.
2

Dateien hochladen

3

Die 3 Dateien aus dem ZIP-Ordner auf deinen Computer speichern

Aus der Claude-Ausgabe hast du diese 3 Dateien erhalten (alle im ZIP-Ordner kita-lernprinzipien):

kita-lernprinzipien/
  ├── index.html  ← der komplette Selbstlernkurs
  ├── README.md   ← Beschreibung des Projekts
  └── 404.html    ← freundliche Fehlerseite

Speichere alle drei Dateien an einem Ort auf deinem Computer, den du leicht findest (z.B. Desktop).

4

Dateien in GitHub hochladen

In deinem neuen Repository siehst du mittig den Text „Add file". Klicke darauf → „Upload files".

Ziehe jetzt die drei Dateien (index.html, README.md, 404.html) in das Upload-Fenster – oder klicke auf „choose your files".

github.com · Upload files
📂 Drag files here to add them to your repository
or choose your files
✅ index.html (110 KB)
✅ README.md (1 KB)
✅ 404.html (1 KB)

Scrolle nach unten zu „Commit changes" und klicke auf den grünen Button „Commit changes". Die Nachricht „Add files via upload" kannst du so lassen.

✅Die 3 Dateien sind jetzt in deinem Repository. Du siehst sie in der Übersicht.
5

GitHub Actions Workflow hochladen (einmalig)

Für die automatische Veröffentlichung brauchen wir noch eine Workflow-Datei. Gehe so vor:

1️⃣
Klicke in deinem Repository auf „Add file" → „Create new file"
2️⃣
Gib als Dateiname exakt ein: .github/workflows/deploy.yml
(GitHub erstellt die Ordner automatisch)
3️⃣
Öffne die Datei deploy.yml aus dem ZIP-Ordner mit dem Editor und kopiere den gesamten Inhalt in das große Textfeld
4️⃣
Klicke auf „Commit changes" → „Commit changes" (grüner Button)
💡Alternativ: Im ZIP-Ordner ist der gesamte .github-Ordner bereits enthalten. Du kannst ihn einfach mit hochladen, wenn du alle Dateien auf einmal per Upload hinzufügst (auch versteckte Ordner).
3

GitHub Pages aktivieren & Link teilen

6

GitHub Pages in den Repository-Einstellungen aktivieren

Klicke in deinem Repository oben auf „Settings" (Zahnrad-Icon). Scrolle in der linken Seitenleiste nach unten zu „Pages".

Settings → Pages
Build and deployment
Source
✓ GitHub Actions  (empfohlen)

Unter „Source" wähle „GitHub Actions". Das war's! GitHub startet automatisch die erste Veröffentlichung.

🚀Der erste Build läuft jetzt – das dauert ca. 1–3 Minuten. Du siehst den Status unter dem Reiter „Actions" in deinem Repository.
7

Deine Website-URL finden und testen

Sobald der grüne Haken unter „Actions" erscheint, ist die Website live. Die URL lautet immer nach diesem Schema:

Deine Website-Adresse

https://DEIN-USERNAME.github.io/kita-lernprinzipien
Ersetze DEIN-USERNAME durch deinen GitHub-Benutzernamen

Du findest die genaue URL auch unter Settings → Pages – dort wird sie nach dem ersten Deployment angezeigt.

💡Öffne die URL in deinem Browser und teste, ob alles funktioniert. Drücke F5 wenn die Seite noch nicht lädt – manchmal braucht es eine Minute.
8

Den Link kannst du auf verschiedene Arten teilen:

💬

Häufige Fragen

💰 Kostet das wirklich nichts?
Ja, GitHub Pages ist für öffentliche Repositories komplett kostenlos – ohne Kreditkarte, ohne Ablaufdatum. GitHub finanziert das als Dienst für die Entwickler-Community.
🔒 Können meine Schülerinnen die Quelldatei sehen?
Ja – das Repository ist öffentlich, d.h. die index.html-Datei ist für alle einsehbar. Das ist bei reinen Lernmaterialien ohne sensible Daten kein Problem. Wenn du die Quelle verbergen möchtest, benötigst du GitHub Pro (kostenpflichtig) für private Repositories mit Pages.
📱 Funktioniert die Website auf Smartphones?
Ja – der Kurs ist vollständig mobiloptimiert und funktioniert auf iPhones, Android-Geräten, Tablets, Laptops und Desktop-PCs.
🌐 Brauchen die Schülerinnen einen Account?
Nein! Die Website ist öffentlich zugänglich. Die Schülerinnen öffnen einfach den Link im Browser – kein Login, kein Account nötig.
🔗 Kann ich eine eigene Domain nutzen? (z.B. kurs.bfs-eichstaett.de)
Ja! Unter Settings → Pages → Custom domain kannst du eine eigene Domain eintragen. Die Domain selbst muss separat registriert werden (ca. 10–15 € / Jahr). Für den Schulgebrauch reicht aber die github.io-Adresse vollkommen aus.
❓ Was, wenn der Link nicht funktioniert?
Prüfe: (1) Ist das Repository öffentlich? (2) Ist GitHub Pages unter Settings aktiviert? (3) Hat der GitHub Actions-Workflow erfolgreich abgeschlossen (grüner Haken unter „Actions")? (4) Stimmt die URL (Benutzername korrekt geschrieben)?
